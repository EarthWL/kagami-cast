Kagami Cast (portable) — รับ Screen Mirroring (AirPlay) จาก iPhone/iPad บน Windows
==================================================================================

แนะนำให้ใช้ตัวติดตั้ง (KagamiCast-x.y.z-setup.exe) ซึ่งทำขั้นตอน 1-2 ให้เอง
ชุด portable นี้สำหรับคนที่ไม่อยากติดตั้งลงเครื่อง

วิธีใช้บนเครื่องใหม่
-------------------
1) ติดตั้ง Bonjour ก่อน (ครั้งเดียว):  ดับเบิลคลิก  INSTALL-Bonjour.bat
   - ถ้ามีอยู่แล้วจะบอกว่าไม่ต้องทำอะไร
   - ถ้าไม่มี winget ให้ลง iTunes หรือ "Bonjour Print Services" จาก Apple แทน

2) เปิด Firewall ให้โปรแกรม (ครั้งเดียว):  ดับเบิลคลิก  Setup-Firewall.bat
   - จะขอสิทธิ์ admin (UAC) กด Yes -- จำเป็น ไม่งั้น iPhone อาจมองไม่เห็นเครื่อง
   - ค่าเริ่มต้นเปิดเฉพาะเครือข่าย Private ถ้า Wi-Fi ของคุณเป็น Public ให้เปลี่ยนเป็น Private
     (Settings > Network & internet > Wi-Fi > ชื่อ Wi-Fi > Network profile type)
     หรือตอบ Y ตอนที่ถามว่าจะเปิดบน Public ด้วยไหม (ไม่แนะนำ)

3) เปิดโปรแกรม:  ดับเบิลคลิก  KagamiCast.exe
   - ตั้งชื่อเครื่อง (ภาษาอังกฤษ/ตัวเลข) / เลือกโหมด (สมดุล แนะนำ) -> กด "เริ่มรับสัญญาณ"
   - โปรแกรมจำค่าที่ตั้งไว้ให้ครั้งต่อไป
   - ครั้งแรกที่กดเริ่มอาจรอสักครู่ (โปรแกรมกำลังเตรียมแคชของตัวถอดรหัสภาพ/เสียง)

4) บน iPhone:  Control Center -> Screen Mirroring -> เลือกชื่อเครื่อง
   ภาพจะเด้งเป็นหน้าต่างแยก ส่วนหน้าต่างโปรแกรมแสดงสถานะ + log

ใช้กับ OBS Studio (OBS 31 ขึ้นไป)
--------------------------------
1) ปิด OBS แล้วดับเบิลคลิก  INSTALL-OBS-Plugin.bat  (ครั้งเดียว)
2) ใน OBS: Sources -> + -> "Kagami Cast (iPhone / iPad)"
3) ใน Kagami Cast ติ๊ก "ส่งภาพเข้า OBS" แล้วกดเริ่ม -> เปิด Screen Mirroring บน iPhone
   - หมุนจอแล้วภาพไม่พอดี: เลือก Source แล้วกด Ctrl+F (Fit to screen) ครั้งเดียว
   - เสียงยังออกลำโพง ถ้าจะอัดเสียงด้วยใช้ Application Audio Capture เลือก uxplay.exe
   - ถอนปลั๊กอิน: ลบโฟลเดอร์  %ProgramData%\obs-studio\plugins\kagami-cast-obs

ข้อกำหนด
--------
- Windows 10/11 64-bit
- iPhone กับ PC ต้องอยู่ Wi-Fi วงเดียวกัน (และเครือข่ายต้องยอมให้ mDNS/Bonjour ผ่าน)
- ต้องมี Apple Bonjour service ติดตั้งบนเครื่อง (ขั้นตอนที่ 1)
- ไม่ต้องติดตั้ง MSYS2/Qt/GStreamer — รวมมาให้ในโฟลเดอร์นี้แล้ว

หมายเหตุ
--------
- ชื่อเครื่องใช้ได้เฉพาะ A-Z, a-z, 0-9, เว้นวรรค และ - _ . ( ) '  (ภาษาไทยใช้ไม่ได้)
- ติ๊ก "ต้องใส่ PIN" เมื่อใช้ Wi-Fi ร่วมกับคนอื่น: PIN จะขึ้นในหน้าต่างโปรแกรม
  iPhone ที่จับคู่แล้วไม่ต้องใส่ซ้ำ (รายชื่อเครื่องที่จับคู่แล้วอยู่ในไฟล์ uxplay.register
  ลบบรรทัดออกเพื่อยกเลิกการจับคู่ของเครื่องนั้น)
- โหมด "หน่วงต่ำสุด" เหมาะกับเกม (เสียงอาจคลาดจากภาพเล็กน้อย)
- โหมด "4K" ต้อง iPhone/จอ/การ์ดจอรองรับ ไม่งั้นอาจกระตุก
- ถ้าภาพไม่ขึ้น ลองโหมด "เข้ากันได้สูงสุด"
- ย้ายทั้งโฟลเดอร์ไปไว้ที่ไหนก็ได้ แต่ย้ายแล้วต้องรัน Setup-Firewall.bat ใหม่
- ค่าที่ตั้ง, log (session.log) และ PIN key เก็บที่  %LOCALAPPDATA%\KagamiCast
